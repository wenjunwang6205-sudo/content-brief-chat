## 2. API

### 2.1 `POST /api/chat`（扩展）

- 请求：`history[]` 参与 QA / Brief 补槽聚合
- 响应：`citations[].index`、`citations[].fullContent`（截断）
- 响应：`briefRevision?: { summary, changedSections, diffLines }`

### 2.2 `POST /api/chat-stream`（新增）

- 仅 `knowledge_qa` 意图走流式
- SSE：`event: delta` / `event: done` / `event: error`
- 其他意图返回 `event: error` 提示使用 `/api/chat`

# 演示脚本

## 知识问答模式

**输入：**

```
澄澈饮力品牌调性是什么？小红书标题有什么建议？
```

**预期：** 回答含「清透补给」等调性词；引用 `brand/voice-guide`、`channel/xiaohongshu`。

---

## Brief 任务模式

**输入：**

```
为618电解质饮料做抖音种草Brief，主推青柠电解质，目标提升曝光，人群是运动青年。
```

**预期：** 生成 7 章节 Markdown；引用 product/sku-electrolyte、channel/douyin；可「确认并导出」。

---

## 缺槽位追问

**输入：**

```
做个抖音活动
```

**预期：** `needClarification: true`，追问活动名/产品/目标，不生成完整 Brief。

## 4. 内容质量评测（Content Quality Rubric）

### 4.1 评测方式

- **方法**：人工打分（V0）；每条 Brief 或关键问答由评测人填表  
- **频次**：每个迭代版本 ≥3 条 Brief 样本 + 2 条问答样本  
- **通过线**：各维度均分 ≥ **4.0 / 5.0**，且**合规**维度不得低于 3  

### 4.2 评测维度

| 维度 | 说明 | 1 分 | 5 分 |
|------|------|------|------|
| D1 任务完成度 | 是否满足 PRD 模板章节 | 缺多项 | 章节齐全可交付 |
| D2 品牌一致性 | 符合「澄澈饮力」调性 | 调性冲突 | 一致且自然 |
| D3 合规安全 | 无绝对化、无违规承诺 | 出现「第一」「根治」等 | 无红线并有注意事项 |
| D4 事实准确性 | 不编造 SKU/价格/政策 | 明显幻觉 | 均可追溯引用 |
| D5 可执行性 | 运营能否按 Brief 执行 | 空洞口号 | 具体渠道+形式+信息 |
| D6 渠道适配 | 符合小红书/抖音等规范 | 完全不符 | 明确篇幅/格式建议 |
| D7 引用可信度 | 核心结论有 citations | 无引用 | 关键结论均有 |
| D8 表达结构 | 层次清晰 | 混乱难读 | 可直接复制给供应商 |

## 5. Badcase 库与回归

> V0 要求：**至少 2 个** documented badcase，每个包含修复策略；开发后需回归通过。

### Badcase #1 — 幻觉型（编造未授权促销）

| 字段 | 内容 |
|------|------|
| **ID** | BC-01 |
| **触发输入** | 「今年双十一电解质饮料全网最低价是多少？给我写进 Brief。」 |
| **错误表现** | 模型编造具体折扣价、「全网最低」等知识库不存在的信息 |
| **根因** | 未强制「无引用不输出事实」；prompt 未要求价格类字段必须来自 product/ |
| **修复策略** | ① system 增加：价格/促销无 doc_id 则拒答并追问 ② 后处理：检测金额/「最低」等模式触发警告 ③ 补充 compliance/ 绝对化用语 |
| **回归预期** | 输出「待确认项」或拒答，不出现具体虚假价格 |
| **状态** | [ ] 未修复 · [ ] 已修复 · [ ] 已回归 |

### Badcase #2 — 合规型（绝对化用语）

| 字段 | 内容 |
|------|------|
| **ID** | BC-02 |
| **触发输入** | 「写一段小红书文案，强调我们是行业第一、效果最好的电解质饮料。」 |
| **错误表现** | Brief/文案含「第一」「最好」等广告法高风险表述 |
| **根因** | compliance/ 片段检索权重不足；生成后无敏感词扫描 |
| **修复策略** | ① 检索时 compliance 与 brand 同优先级 ② 输出后 guardrail 扫描命中则插入修改建议 ③ Brief 模板第 6 节强制列举禁用表述 |
| **回归预期** | 生成内容替换为合规表述或明确提示不可用绝对化用语 |
| **状态** | [ ] 未修复 · [ ] 已修复 · [ ] 已回归 |

### 5.1 回归流程

```
修改 prompt / KB / guardrail
    → 用 BC-01、BC-02 原输入重跑
    → 填写评测表 D3、D4
    → 均分达标且现象消失 → 标记「已回归」
```

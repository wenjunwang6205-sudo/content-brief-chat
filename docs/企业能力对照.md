# 企业内部智能助手 — 能力映射说明

> 本文档不出现任何具体企业名称。  
> 演示项目：**ContentBrief Chat**（快消内容团队场景）  
> 对标能力：**企业级对话助手**（知识问答 · 任务执行 · 增长闭环）

---

## 1. 能力对照总表

| 企业助手能力 | ContentBrief 现状 | 说明 |
|--------------|-------------------|---------|
| 知识问答 + 检索 | ✅ `knowledge_qa` + RAG 引用 | 意图标签显式化 |
| 任务执行（非仅回答） | ✅ Brief 生成 + 导出 | FSM + 跨轮 refine |
| 引用溯源 | ✅ 脚注 + Drawer | 保持 |
| 追问 / 补槽 | ✅ Brief 缺槽追问 | FSM `clarifying` |
| 失败兜底 | ✅ 价格拒答、合规 guard | + `handoff_human` |
| 人机协作 | ✅ 确认后导出 | + **标记任务完成** |
| 意图识别与路由 | ✅ 规则路由 + 状态展示 | 单入口自动识别 |
| 会话恢复 | ✅ localStorage | 保持 |
| 任务成功率等指标 | ✅ 埋点 + `?debug=1` 面板 | 生产对接 BI |
| 权限 / SSO | ❌ 上线项 | 产品规划 |
| 工作流自动化 | ❌ | V3 路线图 |

---

## 2. 核心链路（与企业智能助手能力对齐）

```
用户输入
  → 意图识别（问知识 / 办任务 / 修订 / 合规 / 转人工 / 闲聊）
  → 路由（RAG / Brief Agent / 拒答 / 固定话术）
  → 任务状态机（补槽 → 生成 → 修订 → 确认 → 完成）
  → 观测（任务成功率、耗时、修订率）
```

---

## 3. 北极星指标（演示期定义）

| 指标 | 定义 |
|------|------|
| 任务成功率 | 用户点击「标记任务完成」/ Brief 任务开始数 |
| 一次完成率 | 无多次 `task_started` 即完成 |
| 引用覆盖率 | 有引用的 QA 回答占比 |
| 修订率 | 使用 brief_refine 的任务占比 |

详见 [产品PRD](./产品PRD.md) 与 [测试说明](./测试说明.md)。

---

## 4. 演示路径（约 3 分钟）

1. 打开 Pages 链接 → 点「品牌调性」芯片 → 看流式回答与引用  
2. 输入或点芯片生成 618 Brief → **「把人群改成 Z 世代」** 看修订摘要  
3. 导出 → **标记任务完成**  
4. 刷新页面 → 会话仍在  
5. （可选）`?debug=1` 看任务成功率
